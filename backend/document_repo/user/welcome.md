This is a **sample** document, auto-discovered from `backend/document_repo/user/`.
Delete it (and the other samples) and drop in your own files.

## How documents are organised

Files under `document_repo/` are picked up automatically:

- `document_repo/user/…` → shows in the **User Guide**
- `document_repo/technical/…` → shows in the **Technical Guide**

## Supported file types

| Type | Extensions | How it renders |
| --- | --- | --- |
| Markdown | `.md`, `.markdown` | Full formatting (headings, tables, code) |
| Word | `.docx` | Converted to formatted text in-app |
| Plain text | `.txt`, `.json`, `.log`, `.yml`, `.csv`, `.sql`, … | Verbatim "notepad" view |

> Tip: add a nicer title, description or tags for any file in `config/docs.json`.
